## Почему не сделан полный merge оригинального репозитория

Полная синхронизация рисковала бы удалить `design-to-motion`, которого больше нет в проверенной upstream-main. Все другие новые материалы добавлены выборочно. Оригинал может обновляться независимо: будущие версии следует сверять по смыслу и diff, а не заменять файлы без анализа.

## Техническая проверка

CI использует Python 3.12, `pyyaml==6.0.3`, `python -m unittest discover tests` и `python scripts/validate_skills.py skills`. Для локальной проверки выполнить те же команды. Наличие workflow не означает, что **каждый** тест запустился; итог определяется реальным результатом CI. После merge проверить актуальный `main` и сохранность blob `design-to-motion`.
